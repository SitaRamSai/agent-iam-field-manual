# What Agent IAM Looks Like in 2028

## Thesis

Mature agent IAM will look less like static API keys embedded in automation and
more like workload identity: agent principals, short-lived credentials,
delegated authority, policy-rich tools, and default auditability.

## Reader Promise

By the end of this chapter, a platform engineer should have a concrete mental
model for where agent IAM is likely headed and which bets are durable enough to
make today.

## Draft Outline

1. Summarize what has to become boring infrastructure.
2. Predict the role of agent principals and delegated authorization.
3. Describe policy-aware tools and identity-aware retrieval as defaults.
4. Cover likely open standards and vendor convergence points.
5. End with a pragmatic adoption path for teams starting now.
