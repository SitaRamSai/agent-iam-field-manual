# Chapter 8: What Agent IAM Looks Like in 2028

**Status:** outlined — target ship: Phase 2.
**Length target:** ~1500 words.

## Thesis (one sentence)

The capability-based security models that lost the 1990s OS wars will
quietly win the 2020s agent wars.

## Outline

1. Where 2026 is honest about being early: tooling fragmentation, no
   standards.
2. Three predictions:
   - Identity providers ship agent-native primitives by default.
   - Tool manifests become signed and identity-aware (post-MCP).
   - Capability tokens replace ambient credentials for agents.
3. What platform engineers should bet on now to be ready.
