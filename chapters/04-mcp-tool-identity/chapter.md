# Chapter 4: MCP and Tool Identity

**Status:** outlined — target ship: week 10.
**Length target:** ~2000 words.

## Thesis (one sentence)

Tools are principals too; MCP makes the identity question explicit but
doesn't answer it.

## Outline

1. MCP primer: tools as first-class objects an agent can call. The
   identity question: who is the tool acting as?
2. Tool poisoning: a malicious or compromised tool gains the agent's
   ambient authority. Walk through a realistic attack.
3. Identity-aware tool gating: per-tool credentials, per-tool capability
   tokens, signed tool manifests.
4. What MCP-native identity could look like (forward-pointer).
