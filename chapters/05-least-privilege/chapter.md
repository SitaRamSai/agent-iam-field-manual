# Least Privilege for Agents

## Thesis

Least privilege still applies to agents, but the permission model must account
for delegated user intent, autonomous tool choice, short-lived context, and
policy decisions made at action time.

## Reader Promise

By the end of this chapter, a platform engineer should have a vocabulary for
scoping agent authority without blocking every useful workflow behind manual
approval.

## Draft Outline

1. Translate subject, action, resource, and context into agent workflows.
2. Contrast service-account authority with delegated user authority.
3. Cover scoped tools, short-lived credentials, and just-in-time access.
4. Show policy checks at retrieval, planning, and execution boundaries.
5. End with a practical least-privilege checklist.
