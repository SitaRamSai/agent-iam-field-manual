# Identity-Aware Memory and Retrieval

## Thesis

Agent memory and retrieval are not neutral context stores. They are
authorization surfaces, and they need the same care as databases, search
indexes, and internal knowledge systems.

## Reader Promise

By the end of this chapter, a platform engineer should know where permission
checks belong in retrieval-augmented agent systems and why post-retrieval
filtering is usually too late.

## Draft Outline

1. Identify memory and retrieval as data access paths.
2. Explain tenant isolation and document-level permissions.
3. Cover retrieval poisoning and stale permission snapshots.
4. Show how identity should flow into indexing and query-time retrieval.
5. Define audit requirements for retrieved context.
